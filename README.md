
# CampusConnect – Better College Life

CampusConnect is a college community website that helps students discover campus events, explore clubs and activities, and stay updated with important announcements.

## Features

- Home page with a welcome section.
- Campus events and registration links.
- Clubs and student activities.
- Campus announcements.
- Contact form.
- About section.
- Responsive navigation bar.
- Mobile-friendly layout.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore CampusConnect!

## Note

This is a frontend-only project. Forms demonstrate user interaction but do not store or send submitted data.
